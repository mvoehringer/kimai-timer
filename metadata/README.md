# Screenshots for the Raycast Store

Drop the store screenshots here as PNG, then delete this file — the Store expects
nothing but images in `metadata/`.

- **Exactly 2000 × 1250 px** (16:10). Raycast's window recorder produces this size:
  open the command, then run "Export Screenshot" from Raycast's developer actions
  (`⌘K` inside a development command).
- **3 to 6 images**, named `kimai-timer-1.png`, `kimai-timer-2.png`, …
- Same background in all of them, good contrast, no other apps visible.
- **No real customer or project names** — the screenshots are public. Point the
  extension at a test instance or rename entries before capturing.

Worth showing: the menu bar with a running timer and the Continue list, the
timesheet list, the start form, and the report.
